# Sicherheit

Sicherheitslücken bitte **nicht** als öffentliches Issue melden, sondern über «Report a vulnerability» (GitHub Security Advisories) in diesem Repository.

Besonders interessiert uns alles, was es erlaubt,
- ein gespeichertes Original, Manifest oder Audit-Ereignis unbemerkt zu verändern,
- eine Signatur zu fälschen oder einen fremden Schlüssel unterzuschieben,
- beim Import eine Datei von einer nicht zum Herausgeber gehörenden Quelle einzuschleusen,
- über Dokumentinhalte das Verhalten der Software zu steuern.

Wir bestätigen den Eingang innert 5 Arbeitstagen.
